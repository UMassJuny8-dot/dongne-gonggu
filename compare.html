동네공구함, 전과 후

같은 서비스를 "예쁘게"만 말해서 만든 화면(before)과, 오늘 배운 규칙·스킬로 다시 만든 화면(after)이에요. 완성된 서비스는 여기에서 직접 써 볼 수 있어요.

노트북 1440px

휴대폰 320px

슬롭 체크리스트

8before0after (8개 중, 적을수록 좋아요)
#이런 모습이 있나?beforeafter
1컴퓨터 기본 글꼴 그대로✔–
2가운데 정렬 큰 제목 + 파랑·보라 그라데이션 배경✔–
3크기·간격·그림자가 전부 똑같은 카드 6개✔–
4제목·본문 크기 차이가 작아 무엇이 중요한지 안 보임✔–
5색이 여기저기 제각각 (파랑·남보라·보라가 섞임)✔–
6버튼에 마우스를 올리거나 눌러도 변화 없음✔–
7휴대폰 폭에서 글자가 넘치거나 겹침 (320에서 604px로 넘침)✔–
8이름만 바꾸면 다른 회사 것과 똑같음✔–

바뀐 점 5가지

  1. 하나의 뚜렷한 스타일파랑·보라 그라데이션 + 이모지 카드 → 철물점 공구 벽(페그보드). 공구를 모양으로 고르는 화면 자체가 디자인
  2. 폰트 페어링시스템 기본 글꼴 → 제목 Do Hyeon(간판 같은 고딕), 본문 Gothic A1
  3. 크기 대비로 위계제목 40px에 '빌리기' 버튼 6개가 같은 무게 → 제목 80px, 코발트 버튼은 '공구 빌리기 예약' 하나뿐
  4. CSS 변수 토큰 · 8px 그리드색 값이 제각각 → --color-* 12개, --space-* 8단계만 사용
  5. 상태 디자인 · 모션 규칙hover/focus/active 없음 → 5가지 상태 + 공구를 고르면 고리에 걸린 채 흔들림, transform·opacity만, 모션 줄이기 존중
